**Bumpster** — это мощная утилита для автоматизации семантического управления версиями. Название объединяет *"bump"* и *"buster"*, подчёркивая её способность быстро и эффективно управлять версиями ваших программных проектов.

## Основные возможности

- Поддержка автоматического повышения версии для **major**, **minor** и **patch** обновлений.
- Работа с Git для управления релизами без необходимости в `git-flow`.
- Настраиваемые имена веток для `master` и `develop`.
- Глобальные и локальные файлы конфигурации для гибкости.
- Опциональное логирование всех операций.
- Минимальное влияние на систему: устанавливается в `~/.bumpster`.
- Простое удаление: удалите директорию `.bumpster`, чтобы удалить утилиту.
- Кроссплатформенность (Linux, macOS и Git Bash на Windows).

## Установка

Установить Bumpster можно одной командой:

```bash
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/phoenixweiss/Bumpster/main/install.sh)"
```

Утилита будет установлена в вашу домашнюю директорию в папке `~/.bumpster`.

После установки добавьте Bumpster в PATH:

```bash
echo 'export PATH="$HOME/.bumpster/bin:$PATH"' >> ~/.bashrc
source ~/.bashrc
```

Для **Git Bash на Windows**:

```bash
echo 'export PATH="$HOME/.bumpster/bin:$PATH"' >> ~/.bash_profile
source ~/.bash_profile
```

## Использование

### Повышение версии

**Повышение major версии**:

```bash
bumpster --major
# или
bumpster -M
```

**Повышение minor версии**:

```bash
bumpster --minor
# или
bumpster -m
```

**Повышение patch версии**:

```bash
bumpster --patch
# или
bumpster -p
```

### Отображение текущей версии

Чтобы показать текущую версию Bumpster:

```bash
bumpster --version
# или
bumpster -v
```

### Получение справки

Чтобы получить справку и увидеть доступные параметры:

```bash
bumpster --help
# или
bumpster -h
```

### Обновление Bumpster

Чтобы обновить Bumpster до последней версии:

```bash
bumpster --update
# или
bumpster -u
```

### Проверка статуса репозитория

Чтобы проверить текущий статус репозитория:

```bash
bumpster --status
```

Это покажет:

- Текущую ветку.
- Количество незафиксированных изменений.
- Количество неподнятых коммитов.

### Создание локального файла конфигурации

Сгенерируйте локальный файл `.bumpsterrc` в вашем проекте:

```bash
bumpster --create-local-config
```

Это запустит интерактивный процесс настройки.

## Конфигурация

Bumpster использует файлы конфигурации (`.bumpsterrc`) для настройки своего поведения. Поддерживаются два типа файлов конфигурации:

- **Глобальная конфигурация**: находится в `~/.bumpsterrc`.
- **Локальная конфигурация**: находится в директории проекта (`./.bumpsterrc`). Локальная конфигурация имеет приоритет над глобальной.

### Пример конфигурации

```bash
# ~/.bumpsterrc или ./project/.bumpsterrc
GIT_MASTER_BRANCH="main"
GIT_DEVELOP_BRANCH="dev"
ENABLE_LOGGING="true"
LOG_FILE="bumpster.log"
```

## Требования

- [curl](https://curl.se/)
- [bash](https://www.gnu.org/software/bash/)
- [git](https://git-scm.com/)

Перед использованием Bumpster убедитесь, что у вас инициализирован Git-репозиторий.

## Удаление Bumpster

Чтобы полностью удалить Bumpster, удалите директорию `~/.bumpster`:

```bash
rm -rf ~/.bumpster
```
