# Брендовые материалы Bumpster

У Bumpster две формы айдентики: **Flat** для графических поверхностей и
**Terminal** для моноширинных текстовых сред. Обе развивают одну идею счётчика
релизов: `X.Y.Z`, где каретка над `Z` обозначает повышение версии.

## Основные материалы

| Файл | Назначение |
| --- | --- |
| `bumpster-mark.svg` | Самостоятельный знак Flat |
| `bumpster-lockup.svg` | Основной знак Flat с названием |
| `bumpster-favicon.svg` | Маленькая иконка браузера; оптическое кадрирование ячейки `Z` |
| `bumpster-app-icon.svg` | Полноформатный исходник иконки приложения с безопасными полями |
| `bumpster-social-card.svg` | Исходник социальной карточки 1200 × 630 |
| `bumpster-flat-terminal-sheet.svg` | Референс форм Flat и Terminal |
| `bumpster-favicon-sheet.svg` | Конструкция и размерный ряд favicon |

Для инструментов и поверхностей без поддержки SVG приложены версии PNG.
Название в основном SVG набрано IBM Plex Mono Bold, переведено в контуры и не
зависит от установленного шрифта.

## Форма Terminal

```text
+---+ +---+ +-^-+
| X |.| Y |.| Z |  BUMPSTER
+---+ +---+ +---+
```

Форма Terminal состоит только из печатных символов 7-bit ASCII, занимает три
строки и 27 колонок. Её интервалы следует сохранять без изменений. В цветном
интерактивном выводе выделяются каретка и `Z`; перенаправленный вывод,
`NO_COLOR` и `TERM=dumb` остаются неокрашенными.

## Палитра

| Роль | Hex |
| --- | --- |
| Основной бордовый | `#941E3D` |
| Сигнальный розовый | `#D85A78` |
| Тёплый акцент | `#E7A06C` |
| Бумага | `#F3F0EA` |
| Текст | `#171717` |
| Нейтральный серый | `#706A64` |

Когда позволяет место, используйте полный знак Flat или локап. В размерах
favicon используйте подготовленное кадрирование увеличенной ячейки `Z`, а не
уменьшенный трёхчастный знак.
